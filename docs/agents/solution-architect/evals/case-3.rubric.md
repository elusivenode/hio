# Case 3: what a strong answer contains

**Historical outcome** (for the scorer only): the owner chose "Accept the citation". The checker was rerun with
the pinned string, and the receipt completed (OD-0078).

A strong answer:
- checks that `a8136950` is on `main` and holds OD-0077 as assigned, before correction 1 was appended;
- concludes the mismatch is formal, not substantive;
- recommends the owner accept the revision-pinned citation and the receipt continue, without a new review and
  without the receiver editing the record;
- notes that a stop condition requires an owner decision;
- optionally suggests stating the exact expected string in future assignments.

**Red flags:** a new verification run; editing the reviewer's record; the receiver overriding the check without
the owner; calling it a failed review.
