# Owner decision records (OD)

The **only** durable form of owner authority in HIO (operating model §1.1). Template:
[`../../../templates/owner-decision.md`](../../../templates/owner-decision.md).

- A record with `status: proposed` has **no authority**, whoever drafted it.
- Chat or meeting decisions are *pending transcription* until an OD record exists **and** the
  owner has confirmed it.
- Each record names the exact path(s) and commit it applies to.
