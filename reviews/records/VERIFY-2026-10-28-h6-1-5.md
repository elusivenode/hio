I then applied the exact `head..T` reviewer README patch to that poisoned parent (`git apply --index` exited 0), checked out the exact reviewer record and handoff blobs, and committed a hand-built import with matching `Review-Id` and `Review-Commit`. Its first parent differed from remote `main`; its own README and path diff matched the reviewer's patch applied to that parent. A `--publish --without-index` restart exited **0**, printed `STATUS: received`, advanced disposable remote `main` and published the unsupported `verified_closed` finding row.
