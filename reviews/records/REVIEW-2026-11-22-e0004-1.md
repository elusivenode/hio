## Findings

### F-REVIEW-2026-11-22-e0004-1-1 — high, open: first-release CPI state was not established

The adopted preregistration requires each CPI index level **as first published**, retained release bytes, and later corrections recorded beside but not substituted for that value. `tools/bls_cpi_fetch.py:178-190` downloads one contemporary flat file and only a small release sample; `tools/e0004_state.py:20-54` reads levels solely from that flat file and uses release dates as if those levels were available then. It neither maps all levels to first-release tables nor records later corrections. `cpi-first-release-check-1.md:14-23` acknowledges a limited sample and an uncommitted parser; `step1-1.md:12` then uses the flat file without recording a design amendment or a complete first-release check. A correction to any unsampled level could alter an as-of year-on-year rate and therefore state, screen, interval and decision. The tests pass with invented flat files and do not exercise a first-release/later-correction disagreement. This is an implementation and evidence failure against the adopted input rule, **not** proof that an actual CPI level changed. Remedy requires an owner-approved path for establishing first-release levels at the months used, or a prospective amendment and new authorised run; the existing run must not be silently relabelled as first-release.

### F-REVIEW-2026-11-22-e0004-1-2 — high, open: public evidence contains restricted derived measurements

OD-0176 and `registers/sources.yaml:295-310` keep EODHD personal-evaluation raw and derived data and results in local research for the owner and HIO agents, state that nothing goes into the public repository, and deny quotation in documents and third-party distribution. `tools/e0004_info.py:141-144` derives stress measurements from the EODHD SPY return; `tools/e0004_precision.py:184-187` derives its width from EODHD portfolio returns. The public `step1-1.md:14-26` and `step1b-1.md:14-22` publish those measurements; `result-1.md:12,32-34` repeats a stress comparison and the precision measure while saying no EODHD-derived value is recorded there. No licensed input was read for this finding: it follows from the code's data flow and the already-public report fields. Remove or replace the published derived measurements in a separately authorised remediation and determine the permitted level of qualitative reporting under the rights record. This review does not grant distribution permission or decide vendor terms.
