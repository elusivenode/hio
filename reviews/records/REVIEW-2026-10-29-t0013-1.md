## Finding

### F-REVIEW-2026-10-29-t0013-1-1 — medium, open: the probe scan still reads ignored regular files

T-0013 A-4 requires the probe secrets test to skip both directories **and ignored files**. In `tests/test_t0012_infra.py:161-166`, the new filter is only `p.is_file()`. It skips `.terraform/`, but it includes a regular file such as `infra/tofu/probe/local.tfvars`; `.gitignore` ignores `*.tfvars`, as independently confirmed by `git check-ignore`. The test then reads and checks the file even though its name says it is checking what is *committed*. A local ignored tfvars file with an email or GUID makes the suite fail while the committed probe module is unchanged. That is the same environmental coupling A-4 was meant to remove, and its explicit ignored-file acceptance condition is unmet. Limit the scan to tracked probe files, or exclude ignored regular files as well as directories; verify with both a `.terraform/` directory and an ignored `.tfvars` file present. I did not create a tfvars file in this checkout.
